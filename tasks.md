## Phase 0: RAPID Research

### Workstream 0.1: Team Locations Analysis
- [ ] Collect team member locations (country, city, timezone)
- [ ] Update `team-locations.json` with all attendees
- [ ] Calculate regional distribution (EMEA, APAC, Americas)
- [ ] Identify visa restriction flags by nationality
- [ ] Determine optimal timezone overlap windows

### Workstream 0.2: Candidate Cities Identification
- [ ] Generate initial list of 8-10 candidate cities
- [ ] Filter by visa accessibility (eliminate high-restriction cities)
- [ ] Filter by flight connectivity from major team hubs
- [ ] Shortlist to 3-5 finalist cities
- [ ] Document pros/cons in `locations.json`

### Workstream 0.3: Flight Analysis
- [ ] Map team locations to nearest major airports
- [ ] Research flight costs to each candidate city
- [ ] Estimate average flight cost per person per destination
- [ ] Identify complex routing (multi-leg flights, long layovers)
- [ ] Calculate total flight budget per location option

### Workstream 0.4: Hotel Pricing Research
- [ ] Research hotel availability for summit dates
- [ ] Get group rate quotes (40+ rooms)
- [ ] Compare 3-4 star vs 4-5 star options
- [ ] Factor in breakfast/meeting room inclusions
- [ ] Update `locations.json` with hotel estimates

### Workstream 0.5: Visa Matrix Build
- [ ] List all team member nationalities
- [ ] Research visa requirements for each candidate city
- [ ] Populate `visa-matrix.json` with requirements
- [ ] Flag advance visa requirements (lead time needed)
- [ ] Calculate "visa complexity score" per destination

### Workstream 0.6: Cost Build-Up
- [ ] Run `budget-calculator.py` for initial estimates
- [ ] Build per-location cost comparison
- [ ] Add contingency buffer (10-15%)
- [ ] Create executive summary for RAPID decision
- [ ] Present options to decision-makers
